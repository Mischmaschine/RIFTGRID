# Changelog

All notable user-visible changes are recorded here. This project is under active development and has not declared a stable public API.

## Unreleased

### Added

- Public RIFTGRID V6 commercial landing site and product pages.
- Universal installer model and Custom Docker/OCI deployments.
- Minecraft and FiveM adapters with capability-driven UI behavior.
- Persistent backup, restore, retention, and managed MariaDB/MySQL resources.
- Deployment templates, RBAC, organization settings, node policies, and live infrastructure inventory.
- GitHub Actions CI, repository templates, security policy, and operator wiki.

### Changed

- Overview now preserves live Kubernetes workload counts per node.
- Kubernetes event timestamps are normalized across Date and serialized-string clients.
