03 / TXADMIN

RIFTGRID does not need to rebuild txAdmin on day one. It can make txAdmin part of a larger operational product.

01 / INTEGRATE

Ship with FXServer.

txAdmin is provisioned as part of the FiveM server lifecycle instead of being treated as a separate mystery URL.

03 / COMPLEMENT

RIFTGRID handles the infrastructure.

Backups, node placement, storage, cluster health, database provisioning and migrations remain responsibilities of the control plane.
