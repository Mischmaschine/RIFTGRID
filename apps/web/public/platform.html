01 / CONTROL PLANE

One state model.
Every action traceable.

Start, stop, move, backup, restore and reinstall are not random commands. They are controlled transitions in a server state machine.

DESIRED STATE

RUNNING is a promise.

The user requests a target state. RIFTGRID reconciles actual state until the server reaches it — or records exactly why it cannot.

STATE MACHINE

No impossible transitions.

STOPPED → STARTING → RUNNING. RUNNING → BACKING_UP → RUNNING. Invalid transitions are blocked before they cause undefined behavior.

EVENTS

Everything leaves a trail.

Who restarted what, which node was selected, when a backup finished, why capacity failed — all captured as structured activity.

ERROR MODEL

Errors people can act on.

NO_CLUSTER_CAPACITY is a product state. “Internal server error” is not.
